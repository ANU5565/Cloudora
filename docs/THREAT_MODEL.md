# Cloudora Threat Model & ASVS Matrix

| Threat ID | Threat / Attack Scenario | Affected Component | Mitigation Implemented | Verified Test | Residual Risk |
|---|---|---|---|---|---|
| **THREAT-01** | **IDOR / Cross-User File Retrieval:** Attacker crafts requests using User B's file UUID. | File API (`/files/{id}/download-intent`) | Server strictly verifies `File.owner_id == user.id`. Direct file access attempts return HTTP 403. | `tests/test_security.py::test_tenant_isolation_and_security_boundaries` | Low |
| **THREAT-02** | **Cross-User Modification / Deletion:** Attacker attempts to rename or delete another tenant's file or folder. | Files & Folders API | Mutations require tenant ownership check before any DB write or storage deletion. | `tests/test_security.py` | Low |
| **THREAT-03** | **Concurrent Quota Bypass:** Attacker fires multiple simultaneous large uploads to bypass the account storage limit. | Quota Service & Upload Sessions | Atomic reservation: pending upload sessions hold a reservation lock on quota. Exceeding quota raises HTTP 413. | `tests/test_quotas.py::test_quota_enforcement` | Low |
| **THREAT-04** | **Database Credential Dump / Token Exposure:** Attacker steals database snapshot containing share links. | Shares table & Auth | Share tokens are hashed with SHA-256 before insertion. Passwords hashed with salted bcrypt. | `tests/test_shares.py` | Low |
| **THREAT-05** | **Path Traversal via Uploaded Filename:** Attacker uploads `../../etc/passwd` to overwrite files or escape storage. | Storage & Security core | `normalize_filename()` strips all path separators, null bytes, and control characters. Random UUID prefixes internal keys. | `tests/test_files.py` | Negligible |
| **THREAT-06** | **Folder Cycle Denial of Service:** Attacker attempts to move Folder A into its own subfolder, causing infinite recursion. | Folder Service | Cycle detection checks complete ancestor hierarchy before committing parent updates. | `tests/test_folders.py::test_folder_hierarchy_and_cycles` | Negligible |
| **THREAT-07** | **Accessing Trashed / Revoked Content:** Attacker uses old link or tries to download trashed file. | Download & Share API | Trashed files are rejected with HTTP 400. Revoked/expired shares return HTTP 404/410. | `tests/test_security.py` & `test_shares.py` | Low |
| **THREAT-08** | **Sensitive Data Leakage in Application Logs:** Tokens, passwords, or presigned URLs appear in log collectors. | Logging Core | `SafeJsonFormatter` intercepts log streams and redacts sensitive keys matching passwords, secrets, tokens, and cookies. | Inspected & configured | Low |
